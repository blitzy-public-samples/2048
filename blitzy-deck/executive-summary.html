Data flow

Figure 4 — Turn Data Flow: From Keystroke to Composited Frame and Persisted Run State 

flowchart TD
  SS["onStageStart dispatch
as the stage board is prepared"]
  SS --> K["Key, swipe or on-screen control"]
  K --> D["Direction 0 to 3"]
  D --> GUARD{"Play blocked?
lost, or won and not continued"}
  GUARD -->|"yes"| END0["Turn refused, nothing emitted"]
  GUARD -->|"no"| BM["onBeforeMove dispatch
cancellable, may redirect,
may record board commands"]
  BM -->|"vetoed, board unchanged"| END1["Turn ends, no state change"]
  BM -->|"vetoed, a command reseated the board"| SETTLE["Verdict re-derived,
no spawn"]
  BM -->|"allowed"| PREP["prepareTiles
clear mergedFrom, snapshot position"]
  PREP --> TRAV["Traversal walk
over the configured board size"]
  TRAV --> MG{"Merge condition
from config.merge.canMerge?"}
  MG -->|"yes"| MH["onMerge dispatch
score delta applied"]
  MG -->|"no"| MV["Reposition tile"]
  MH --> CHK["Win check on the merged value
against config.winValue"]
  CHK --> MOVED{"Any position changed?"}
  MV --> MOVED
  MOVED -->|"no"| END2["Turn ends, no spawn"]
  MOVED -->|"yes"| SP["Spawn: value and position from
named RNG substreams,
then onSpawn dispatch"]
  SP --> LOSS{"Moves still available?"}
  LOSS -->|"no"| OVER["Game over recorded"]
  LOSS -->|"yes"| AF
  OVER --> AF["onAfterMove dispatch
may declare the run over,
may record board commands"]
  AF --> MA["move:after emitted
run controller measures goal progress"]
  MA --> COMMIT["commit
1 best score promoted, then re-read
2 board snapshot written or cleared
3 state:commit emitted, ten members"]
  SETTLE --> COMMIT
  COMMIT --> R["Renderer tweens
and composites a frame"]
  COMMIT --> VIEWS["HUD, announcer, sound engine
and screen router"]
  COMMIT --> PERSIST["Run state written
under a namespaced key"]
  COMMIT --> SG{"Stage goal met?
evaluated after the commit"}
  SG -->|"no"| WAIT["Await next input"]
  SG -->|"yes"| SE["endStage: onStageEnd dispatch,
then stage:end emitted"]
  SE --> COMMIT2["Second commit of the same turn"]
  COMMIT2 --> SC["Stage clear on screen;
the player's own continue
opens the reward offer"]
