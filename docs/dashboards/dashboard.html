Export a snapshot first

This page renders a snapshot you supply. Nothing is fetched, and no sample data ships with it, so the panels below stay empty until a real export is loaded.

  1. Run the game with the diagnostics overlay requested, and play a few turns so the counters and both histograms move.
  2. Press Export metrics for game2048-metrics.prom, or Export snapshot for game2048-diagnostics.json, which also carries the health, readiness and hook sections. The third form this page reads has no control of its own: call __blitzy2048.metrics.download("game2048-metrics.json") from the console — any .json filename writes the metrics snapshot rather than the Prometheus text.
  3. Load that file above, by any of the three routes.

docs/OBSERVABILITY.md has the full procedure: how the overlay is requested, what each capability looks like when it is working, and how to exercise every one of them locally.

Series, labels, bucket boundaries and check identifiers are declared in src/observability/metrics.ts, src/observability/health.ts, src/engine/hooks.ts and src/engine/engine-events.ts. Thresholds are cited to the line that sets them. For the reuse record and the substitution table, read docs/OBSERVABILITY.md; for the reasoning behind this artifact, docs/DECISION_LOG.md DL-DIAG-06.
